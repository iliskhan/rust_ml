# Дальнейшее развитие API

Обновлено: 2026-10-14. Порядок реализации — [PLAN.md](PLAN.md).

## Уже существует

- `Scalar<T>` и `IntoScalar` позволяют обходить ограничения orphan rules для операций слева.
- Операторы возвращают `Result`, поэтому промежуточные вычисления завершаются `?`.
- `Tensor` и `Variable` доступны через facade `rustml`.
- `Linear`, `mse_loss` и `Sgd` также доступны через facade; пример линейной регрессии
  использует настоящий autograd. Параметры слоя владеют `Variable`.
- `Variable::relu` и `Linear::with_seed` позволяют обучать небольшой MLP на XOR.
  Проверяются градиенты композиции и воспроизводимость; Module/Sequential не нужны этому примеру.

## Ближайшие решения

- Выбирать следующую операцию и loss на основании конкретного учебного сценария.
- Нулевая инициализация Linear подходит для одного affine-слоя; для MLP использовать
  `with_seed` с отдельным seed слоя, чтобы нарушить симметрию нейронов.
- Изменять только уникальные leaf-параметры после освобождения графа. Новый training step строит новый граф.
- Определять API сохранения модели на основе работающего training example и задачи восстановления.

## Отложено

Expression DSL, универсальные builders, convenience-макросы, higher-order derivatives,
GPU и distributed training. Наличие возможного синтаксиса само по себе не оправдывает новую абстракцию.
Устаревшие примеры несуществующего API удалены; работающий синтаксис проверяется в README и tests.
