# UI/UX Learning Lab — приёмка 2026-10-11

Интерфейс уточнён поверх рабочего учебника: явный первый опыт, ранний словарь,
точный ввод параметров, переходы внутри длинных уроков и обучение рядом с картой.

успешность обучения пользователей не измерялось.

## Как повторить и пределы

`pnpm install --frozen-lockfile`, команды выше, затем `pnpm preview --port 5183 --strictPort`
на свободном порту. Повторить ручные сценарии через обычные элементы интерфейса,
используя записанные viewport и параметры. Перезагрузка сбрасывает состояние —
интерфейс сообщает об этом; сохранение между перезагрузками не добавлялось.

Новые численные тесты не нужны: вычислительные модули неизменны. Нативный ввод,
focus и layout проверены в браузере, без тестов, повторяющих код компонента.
Это не полный WCAG-аудит: screen reader, touch assistive technology, отдельный
режим200% text zoom и runtime reduced-motion не проверены. Задержка сети для
Suspense не эмулировалась; общий mount подтверждён чтением кода и обычной
загрузкой. Не заявляется повторная визуальная приёмка всех глав учебника.

Следующий шаг на момент записи отчёта — commit, обычный push этой ветки и
сверка remoteSHA. Результат доставки сообщается в завершении задачи; основной
master автоматически не объединяется.
