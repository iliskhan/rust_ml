## Пределы проверки и дальнейшее исследование

- Проверены клавиатура, focus, native dialog, семантические названия и reflow.
  Полного прогона с NVDA/VoiceOver не было; доступное дерево не заменяет его.
- Системное уменьшение движения не переключалось. В исходниках сохранено
  существующее правило `prefers-reduced-motion`; новые элементы не добавляют анимаций.
- Ctrl+plus в IAB не дал подтверждённого изменения масштаба. Проверка640px —
  проверка reflow, а не доказательство text-only zoom200%. Это отдельная ручная проверка.
- Исследования с реальными новичками не проводились. Следующий короткий сценарий:
  без подсказки найти градиент и вернуться к числам; включить ReLU только b;
  объяснить, почему causal даёт Y=V₀; сравнить Adam/SGD с одинаковыми данными,
  seed и бюджетом. Записывать ошибки, места остановки и объяснение своими словами,
  не выводить успешность обучения только из кнопки «Выполнено».
- Сохранение между перезагрузками пока относится к Boundary. Остальные уроки
  сохраняют состояние при переходах в текущей вкладке. Completion заданий не хранится.
- Форматv1 восстанавливает данные из seed; изменение генератора требует новой версии
  формата или миграции. История проверяется по форме и последней фактической потере,
  промежуточные точки импортированного файла не являются доказанным журналом обучения.

Git delivery выполняется после этой приёмки; точный итоговый SHA и совпадение remote
сообщаются в завершении чата. Merge и публикация сайта в задачу не входят.
