## Замечания P2 с математическим или педагогическим последствием

1. **Sampling, t22–40: CDF назван teacher forcing.** `sampling.py:87` проходит через LABELS на строке 10: полная фраза «Генерация выбирает; teacher forcing задаёт префикс» заменяется на «teacher forcing». Эта подпись стоит непосредственно под полосой CDF со случайным маркером u=.42 и выбранным ID 2. Получается неверная идентификация: teacher forcing подставляет известный префикс, а здесь показан случайный выбор из распределения. Нужна короткая подпись `sampling` у CDF; `teacher forcing` можно поместить у отдельных строк вход/цель в сравнении.

2. **Crossmask, t22–40: j≤i визуально относится к обеим картам.** `crossmask.py:80`, сокращение LABELS: из «Causal: j ≤ i / Cross: Q decoder, KV encoder» остаётся только общая нижняя подпись `j ≤ i`. Справа cross-карта имеет ненулевые элементы вне такого треугольника. Это противоречит центральному вопросу сцены о необходимости causal-маски для encoder memory. Перенести условие непосредственно под левую causal-self карту, справа оставить короткие Q decoder / KV encoder.

3. **Recurrent, t22–40: h RNN выглядит как h той же LSTM, чья c приведена ниже.** `recurrent.py:69,76,81–82`: основная строка берётся из `n.rnn[].h`, но подписана только `t → h`; ниже появляется `c: LSTM`. Например h₀≈.63 и c₀≈.38 не могут быть h/c одной LSTM, поскольку |h₀|≤tanh(|c₀|)≈.36. Нужна короткая явная маркировка `h: RNN` основной строки; данные менять не требуется.

4. **MLA, t15–40: стрелки показывают ложную зависимость output от одного latent.** `mla.py:65–66,78–84` берёт только последний x и c=[−1.12243,−.03133], затем стрелками соединяет этот c с output=[−.34832,−.07297]. По fixture это attention-агрегат по шести токенам с весами [.17327,.20665,.16147,.13918,.16827,.15117], а не декодирование c последнего токена. Для сравнения, V последнего токена head0=[−.53928,−.90421]. Нужны несколько ячеек памяти и узел Σαᵢcᵢ перед выходной проекцией; отдельно показать kᴿ. Одной сменой подписи нельзя устранить ложную причинную стрелку.

5. **SwiGLU, t4 и t9: ответ раскрыт до prediction.** `swiglu.py:65–67` сразу показывает отрицательные SiLU(g)≈−.18 и −.27, тогда как вопрос на t9 спрашивает, всегда ли gate — вероятность в [0,1]. Это уже прямой контрпример до вопроса; требование reveal после12 нарушено. До12 оставить raw g или скрытые activated-ячейки, отрицательные SiLU(g) раскрыть после12.

6. **ViT, t30–40: округление превращает разные результаты в видимое равенство.** `vit.py:86–95`, общий `value`: сравнение `P` / `без P` в обоих случаях отображает [1.2,−.16]. Fixture даёт [1.232320,−.160147] и [1.219104,−.156768]. Ученик получает визуальное свидетельство отсутствия влияния позиции, хотя выбранный пример должен показать изменение. Для двух итоговых координат достаточно трёх знаков после запятой (1.232/1.219 и −.160/−.157) либо отдельного численного Δ.
