## Реализованный сценарий

«Сеть целиком» → «3D: нейроны, связи и обучение по шагам». Десять ручных фаз:
вход, взвешенная сумма, tanh, выход, BCE, выходная чувствительность, цепочка через
tanh, градиенты параметров, среднее четырёх примеров, обновление. 7 нейронов,
12 связей и 5 bias выбираются мышью/клавиатурой, select либо таблицей. Камера
вращается мышью и ползунками; стрелки и Home доступны на SVG, есть вид спереди.

Все числа получены из общих текущих параметров XOR. Trace одного примера не делится
на4; trainer усредняет четыре вклада ровно один раз. Preview использует настоящие
`params/m/v/step`; подтверждение сверяет полное ожидаемое состояние после одного
вызова родительского trainer. Next/back не обновляют веса; после применения есть
отдельный переход к следующему циклу. Локального второго trainer нет.
