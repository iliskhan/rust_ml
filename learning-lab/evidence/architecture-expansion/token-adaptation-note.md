## Ограничения и визуализация

BPE — символьный поток без normalization, pre-tokenization, special tokens и byte fallback, до 500 UTF-16 единиц и 20 слияний. Возможны слияния через пробелы. JSON ключ пары задаёт стабильный порядок UTF-16 при равных частотах. Это явно не промышленный tokenizer.

FFN — d=3, h=4, без bias, ручные фиксированные матрицы. ReLU/GELU имеют 24 веса, SwiGLU 36: ширина одинакова, бюджет не выровнен. Gate = SiLU(g), может быть отрицательным и превышать 1, не вероятность. 3D показывает настоящие тройки выходов y₁,y₂,y₃ при изменении x₁; индексы каналов не используются как оси.

LoRA — слой 8→3, масштаб α/r=1, full-batch SGD, 16 train входов ±2eⱼ, восемь отдельных фиксированных плотных held-out входов. Шум добавлен только к train ответам, held-out ответы чистые; обе кривые наблюдаемые. Инициализация A ненулевая, B=0; 11/22/33 обучаемых весов при r=1/2/3 против 24 full. Высокий rank может убрать экономию. База LoRA всё равно хранится. 3D отображает настоящие выходные тройки базы/цели/full/LoRA для одного входа, без осей эпохи или номера примера.
