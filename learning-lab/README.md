# RustML Learning Lab

Интерактивный учебник на русском: математические основы, полный цикл обучения маленькой сети и подробный разбор Transformer. Вычисления работают локально в браузере; сеть XOR действительно обучается. Самостоятельная учебная реализация на TypeScript, без подключения к RustML API.

## Установка и запуск

Нужны **Node.js 24+** и **pnpm 11.25.0** (версия закреплена в `packageManager`).
Если pnpm ещё не установлен: `npm install --global pnpm@11.25.0`.

На Windows из корня репозитория достаточно одной команды:

```powershell
.\learn.cmd
```

Скрипт работает и при запуске по абсолютному пути из другого каталога. Он проверяет Node,
устанавливает зависимости по lockfile, запускает Vite и открывает браузер. Для другого порта
передайте `.\learn.cmd --port 5181`. При занятом порте сервер завершится с ошибкой, не подключаясь к чужому процессу.

На любой поддерживаемой системе можно выполнить из корня репозитория:

```powershell
cd learning-lab
pnpm install --frozen-lockfile
pnpm dev --port 5180 --strictPort --open
```

Откройте `http://127.0.0.1:5180/`. Сервер слушает только loopback. `Ctrl+C` завершает ваш сервер.
Для pnpm разрешён только необходимый postinstall esbuild (`pnpm-workspace.yaml`); локальные
`node_modules/`, `.pnpm-store/` и `dist/` исключены из Git. Первая установка требует доступа к registry.

## Проверки и production

```powershell
pnpm typecheck
pnpm test
pnpm build
pnpm preview --port 5178 --strictPort
```

`build` повторяет typecheck и создаёт `dist/`. `test` использует встроенный `node:test` и нативное чтение TypeScript в Node 24 — дополнительный test framework не нужен. Lockfile фиксирует версии зависимостей. Статический `dist/` можно обслуживать обычным HTTP-сервером; маршруты основаны на `#hash` и не требуют backend.

## Что можно исследовать

1. **Карта цикла:** данные → слои → предсказание → потеря → обратный проход → шаг веса. Выбор блока раскрывает связь и ведёт к эксперименту.
2. **Нейрон и Linear:** изменяемые входы/веса/bias, отдельные произведения, batch и формы; ReLU, sigmoid, tanh с производными.
3. **Потери:** MSE по трём точкам, вклад и градиент каждой; BCE через вероятность или устойчивую формулу от логита. Объяснено отличие от accuracy.
4. **Backprop:** общий узел q участвует в q²+q; локальные производные и сумма путей. Центральная конечная разность пересчитывает прямой проход.
5. **SGD / momentum / Adam:** одинаковые старт и квадратичная поверхность, реальные траектории; шаг, авто, пауза, сброс, поправка начального смещения оценок Adam.
6. **XOR 2→4→1:** фиксированный seed, tanh и BCE-logits, настоящие forward/backward/update всех 17 параметров, loss history, карта вероятностей и разбор текущего нейрона.
7. **Архитектуры:** численный Dense/MLP, Conv2D, RNN, LSTM, GRU, Transformer. [Точный охват вариантов](docs/architectures.md) отличает работающие расчёты от схем расширения.
8. **Transformer по шагам:** отдельный маршрут от embedding и Q/K/V до голов внимания, позиций, нормализации, кэширования и выбора следующего токена. Полные размерности промышленных моделей здесь не воспроизводятся.
9. **Маршрут с нуля:** карта предпосылок, разделы курса и направления продолжения с явными отметками глубины: работающий эксперимент, текстовый разбор или внешний материал.

## Как углубляться и возвращаться

Нажмите подчёркнутое понятие внутри объяснения. Например: **градиент → производная → функция**.
Каждый разбор содержит простой смысл, пример, связанные основы и подробную формулу.
«На один уровень назад» возвращает к предыдущему понятию; хлебная крошка — к выбранному
предку; «Вернуться к уроку» или Escape — к исходному эксперименту.

Параметры, раскрытые подробности, ответы и положение прокрутки сохраняются при этих переходах.
Смена основного раздела также сохраняет уже посещённые эксперименты. Автоматические шаги XOR
и оптимизаторов ставятся на паузу при углублении или уходе; продолжение запускается явно.
Состояние живёт **до перезагрузки или закрытия вкладки**: аккаунта и сохранения между сеансами нет.
Повторное понятие возвращает к уже открытому уровню; глубина одного пути ограничена восемью
понятиями, с объяснением при достижении границы и сохранением всех экспериментов.

Основные лаборатории содержат формулы с текущими числами, раскрываемые подробности и упражнения с обратной связью. Ползунки управляются стрелками, Home/End; кнопки и select работают с клавиатуры. Анимация запускается явно, имеет паузу и лимит шагов; стили учитывают `prefers-reduced-motion`. Цвет дублируется числами, подписями или стилем линий.

## Архитектура исходников

- `src/math.ts`: чистые вычисления базовых уроков, градиенты, оптимизаторы и сеть XOR.
- `src/architectures.ts`: отдельные малые forward-функции и простой `architectureFamilies` — реестр семейств/поддержанных вариантов/границ.
- `src/Foundations.tsx`, `src/Experiments.tsx`, `src/ArchitectureLesson.tsx`: состояние экспериментов и объяснения. Общего фреймворка графов нет.
- `src/ui.tsx`: подписанный ползунок, адаптивный SVG-график, упражнение и форматирование чисел.
- `src/App.tsx`, `src/styles.css`: навигация, карта, справка и адаптивный интерфейс.
- `src/learning-navigation.ts`, `src/learning-context.tsx`, `src/KnowledgeExplorer.tsx`: путь углубления, сохранение состояния, фокуса и прокрутки, пауза скрытых экспериментов.
- `src/concepts.ts`, `src/conceptMath.ts`, `src/ConceptLesson.tsx`: связанные математические понятия и их эксперименты.
- `src/curriculum.ts`, `src/CurriculumView.tsx`: карта курса с явными границами глубины.
- `src/transformerMath.ts`, `src/TransformerCourse.tsx`: дополнительные вычисления и пошаговый курс Transformer.
- `tests/*.test.ts`: независимые ручные примеры, численные градиенты, детерминированное обучение и проверки attention/causality.

Новый вариант добавляется как небольшая функция/конфигурация соответствующего семейства, интерфейс и независимый численный тест. Новое семейство дополнительно регистрируется в `architectureFamilies`. Схемы без численного расчёта маркируются прямо. Rust-интеграция потребует отдельного адаптера после стабилизации API.

## Упрощения и ограничения

- JavaScript `number`, двойная точность IEEE 754. Интерфейс округляет значения; формулы считают с полной точностью. В списках десятичная запятая — формат отображения.
- XOR использует полный пакет из четырёх примеров, аналитический backward и фиксированный порядок; нет dropout, случайных мини-пакетов или общего autograd engine. Проверенные seed решают этот пример при Adam η=0.03 за 3000 шагов. Это не обещание сходимости любых настроек и не измерение обобщения.
- Сравнение оптимизаторов использует точный градиент. Momentum без Nesterov/dampening; Adam без weight decay/AMSGrad. Выход за |координата|>50 останавливает отдельную траекторию и явно отмечается. Окно графика ограничено, таблица сохраняет действительные числа.
- Архитектуры кроме XOR демонстрируют forward малых конфигураций, без обучения больших сетей и импорта моделей. Отдельный курс Transformer добавляет игрушечные embeddings и выбор следующего токена: это механизм, а не обученная языковая модель. Conv1D/3D, peephole LSTM, reset-after GRU и некоторые другие варианты — схемы расширения. Не обещается поддержка всех опубликованных вариаций.
- Нет AI API, ключей, аккаунтов, базы данных, backend, внешних шрифтов и runtime-запросов. Внешняя сеть нужна для установки пакетов и открытия ссылок на первичные источники.
- Учебник перенесён в основной проект из отдельного worktree; исправления Rust-ядра сохранены.
  Совместное расположение не означает подключения браузерных расчётов к Rust API.
