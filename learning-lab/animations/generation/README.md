# Генерация: сохранить K и V

`CachedGeneration` в `generation.py`: **50 секунд**, 2D, 1280×720, 30 fps.
B12 / R01/R02/R04/R06 / U02/U04/U05/U07/U08. Фильм раскрывает один шаг causal
attention с кэшем и соответствует лаборатории **KV-cache**, а не sampling.
Два первых измерения входа — условные признаки, подписи 0…3 — позиции.
Новая последовательность здесь задана вручную; обученного языкового выбора
следующего токена нет. Просмотр не даёт самостоятельный зачёт.

`export-fixture.ts` извлекает объявленный CACHE_INPUT из TransformerCourse,
а затем вызывает существующие `cachedAttentionStep` и `fullCausalAttention`.
Если литерал CACHE_INPUT изменит форму или исчезнет, экспорт явно завершится
ошибкой; ввод не копируется второй независимой константой. Матрица входов:
[[1,0],[0,1],[1,1],[-1,.5],[.25,-.5],[.5,.75]], rotary=true, causal=true.
Python читает fixture и не воспроизводит численный алгоритм.

Fixture: input/projections/rotary/causal/initialLength=3/nextLength=4,
steps[0..5]. Шаг содержит position/input/query/keys/values/weights/output,
fullOutput и maxError. В экспорт включены только конечные численные данные.
Во всех шести шагах maxError=0 в JavaScript number. В сцене сравниваются
steps[2] и steps[3]; старые строки K/V совпадают точно, появляется одна новая.
Результат на экране округлён, исходные проверки используют полную точность.

RoPE уже применён к сохранённым K по их абсолютным позициям. Новые Q/K
вращаются по позиции 3; V не вращается. Новая строка attention видит ключи
0…3. Старые причинные состояния не зависят от будущего при фиксированных
входах и параметрах. Для нового запроса старые Q не нужны. При изменении
старого входа кэш зависимых состояний надо пересчитать; двусторонний encoder
не поддерживает эту простую append-only схему. Численная эквивалентность
показана для одного существующего учебного attention, не полной LLM.

постер — 30 s. Старые строки во время добавления остаются на своих местах.
Цвет не единственный сигнал: строки имеют номера, таблица — заголовки K/V.
Полоса y < −1.8 свободна. VTT покрывает 0–50 s и включается по выбору.
Текущий `render_support.py` сохраняет немой MP4 и постер PNG. Отдельный
`narration.ru.json` хранит исторические реплики; процесс — в

## Текстовая альтернатива и новый случай

1. После трёх позиций храним три строки K и три строки V.
2. Для входа позиции 3 считаем только новые Q/K/V, учитывая RoPE-позицию 3.
3. Добавляем K/V в конец; прежние строки не меняем.
4. Новый Q сравнивается с четырьмя K, затем его веса смешивают четыре V.
5. Ответ совпадает с последней строкой полного causal attention на префиксе 4.
6. В лаборатории задайте длину 5, rotary=true; сравните cached/full и предскажите
   размер каждой таблицы K/V: пять строк.

Новый вопрос: после построения кэша исправили токен позиции 1. Достаточно ли
просто дописать следующий токен? Нет: изменённые и зависимые K/V устарели;
их нужно пересчитать. Это проверка условия применимости, а не воспроизведение
чисел из фильма. Полевого исследования с учениками пока нет.
