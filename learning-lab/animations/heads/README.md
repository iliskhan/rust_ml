# Четыре головы: собрать ответ

`AttentionHeads` в `heads.py`: **50 секунд**, 2D, 1280×720, 30 fps.
B12 / R01/R02/R04/R06 / U02/U04/U05/U07/U08. Просмотр — разобранный пример,
не самостоятельная проверка. Входы и результаты совпадают с лабораторией
«Головы» в TransformerCourse.

`export-fixture.ts` вызывает существующий `groupedAttention(HEAD_INPUT, n, true)`
для n=4,2,1. Python не реализует внимание заново. Используется запрос позиции
2; четыре Q-головы ширины 2, d_model=4, матрица OUTPUT_PROJECTION размера 8×4.
Fixture содержит input/outputProjection, queryIndex/causal, modes[0..2].
Каждый mode содержит kvHeads/groups/queries/keys/values/weights/headOutputs,
concatenated и output. Строки weights соответствуют головам для позиции 2.

Четыре ответа по два числа склеиваются в восемь **с сохранением порядка**.
Затем `Concat × Wᴼ` даёт четыре выходные координаты. Каждая рамка — одна
пара координат; она не обозначает физическую ось. Четыре пары в узких колонках
округлены до .01; итоговая проекция и веса внимания — до .001. Вычисления
проекции используют полную точность fixture, а не округлённые подписи.

MHA использует группы [0,1,2,3]; GQA — [0,0,1,1]; MQA — [0,0,0,0]. Все четыре
Q-головы остаются. Показанные веса GQA-голов 1 и 2 рассчитаны отдельно и
различаются, хотя K/V совпадают. Это примеры с фиксированными весами, не
конверсия обученного checkpoint и не проверка качества. Сокращение числа
KV-групп уменьшает полезный объём KV-кэша при прочих равных; фильм не обещает
такое же ускорение всей модели. d_model здесь намеренно не равен h×d_head.

## Текстовая альтернатива и новый случай

1. Запрос позиции 2 рассчитывается четырьмя разными головами.
2. Каждая голова даёт два числа; склейка содержит восемь чисел.
3. Проекция 8×4 возвращает четыре координаты.
4. В GQA запросы 1/2 используют общие K/V; 3/4 — другую общую группу.
5. В MQA все четыре запроса используют одну группу K/V.
6. В лаборатории выберите GQA, затем головы 1 и 2: сравните K, V, Q и веса.

Новый вопрос: восемь Q-голов делят две KV-группы. Сколько отдельных Q-голов
остаётся? Ответ: восемь; совместное использование касается K/V. Из того,
что K/V совпадают, не следует равенство весов внимания или ответа.
Исследование с учениками не проводилось.
