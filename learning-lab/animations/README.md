# Анимации учебника

Восемь оригинальных сцен ManimGX0.1.1/Python3.13+: backprop, neuron,
attention, descent, xor, rope, heads, generation. Числа экспортируются из
действующей TypeScript-математики, а Python отвечает за изображение.
Сцены используют тёмный фон, связанные цвета, поэтапный разбор и паузу
для прогноза; видео и персонажи3Blue1Brown не заимствуются.

## Русская озвучка

Реплики и точные интервалы — в `*/narration.ru.json`; язык — русский,
голос — установленный Microsoft Irina Desktop Russian через Windows SAPI.
Это синтезированная речь. Никакой сетевой TTS-сервис или ключ не требуется.
Субтитры содержат также формулы и контрольные числа, показанные в кадре.

Из корня репозитория на Windows с установленным голосом:

```powershell
learning-lab/animations/synthesize-narration.ps1
work/backprop-pilot/venv/Scripts/python.exe learning-lab/animations/assemble-narration.py backprop neuron attention descent xor rope heads generation
work/backprop-pilot/venv/Scripts/python.exe learning-lab/animations/descent/render-assets.py
```

Повторить последний шаг для нужных сцен после экспорта fixtures и `inspect`.
Первая команда подбирает темп0–5 так, чтобы вся реплика помещалась до своей
границы; при невозможности просит сократить текст. Вторая команда проверяет
интервалы, формат PCM22.05kHz/16bit/mono и собирает WAV без обрезания слов.
Оставшиеся промежутки — тишина, включая время на прогноз.

Raw WAV находятся в игнорируемом `work/backprop-pilot/narration/`; их не
нужно доставлять сайту. `render_support.py` добавляет готовый WAV в `setup`
сцены через `Scene.add_sound`. ManimGX сам создаёт AAC внутри MP4; внешний
FFmpeg не нужен. Один рендер создаёт видео со звуком и соответствующий постер.
Справка: [Microsoft SAPI](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/ms723597(v=vs.85)),
локальные API `manimgx/scene.py` и `manimgx/audio/sound.py` версии0.1.1.

Рендереры теперь требуют готовую озвучку: отсутствие WAV — явная ошибка,
а не молчаливый выпуск немого ролика. Разовая проверка одного голоса:
`synthesize-narration.ps1 -Scenes neuron`, затем `assemble-narration.py neuron`.

## Учебные действия

Видеоплеер запускается вручную. При обычном воспроизведении он один раз
останавливается перед объяснением; ответить можно локально или пропустить.
Явная кнопка продолжает видео. Перемотка и главы остаются доступны.
Отдельный новый случай отличается от разобранных чисел и не выдаёт зачёт.

«Применить числа ролика» сохраняет копию текущего состояния лаборатории;
повторное применение не затирает эту копию. «Вернуть мои настройки» восстанавливает
числа и историю, оставляя автоматическое обучение на паузе. Видео не
превращается в динамическую симуляцию: текущие числа меняются в лаборатории.
Текст/таблицы и исходные лаборатории доступны независимо от воспроизведения.
