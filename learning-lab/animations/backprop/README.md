# Два пути к одному градиенту

Сцена `BackpropSharedNode` в `backprop.py`: **44 секунды**, 2D, русский текст,
текущий MP4 без звука. Родитель B12; уточнения R01/R04/R06 и U02/U04/U05/U07/U08.
Это разобранный пример; его просмотр не является самостоятельной проверкой.

## Источник чисел и изображения

`fixture.json` экспортируется из существующего TypeScript `sharedGraph`.
Python читает значения и вклады из JSON; отдельной реализации backprop здесь нет.
Символы `q²`, `2q`, `1` и формулы задают операции, численные результаты берутся
из fixture. В частности, частные производные показаны при текущих значениях
входов; они описывают чувствительность при малом изменении аргумента.

Сценарий и рисунок созданы для RustML, под лицензией проекта
`MIT OR Apache-2.0`. Использованы собственные текст, геометрия и композиция;
сторонних кадров, персонажей, музыки, записей голоса или изображений нет.
Текущий немой рендер и доступные по выбору VTT описаны в
[README анимаций](../README.md). `narration.ru.json` сохранён как исторический артефакт.
Общие приёмы: конкретный пример, постепенное раскрытие зависимости, пауза
для предсказания, устойчивые цвета и перемещение двух слагаемых к их сумме.
Цвет дублируется формулами и положением: квадрат — сверху, прямой путь — снизу.

Движок: **ManimGX 0.1.1**, Python ≥3.13. У движка собственный MIT-код,
но native wheel с x264 распространяется как GPL-3.0-or-later;
wheel не включается в сайт. Информация о дистрибутиве:
[ManimGX License](https://github.com/academa-labs/manimgx#license).
API сверялся 2026-10-16 по официальным руководствам
[text/math](https://manimgx.academa.ai/user-guide/text-and-math/),
[animations](https://manimgx.academa.ai/user-guide/animations/) и
[render/inspect](https://manimgx.academa.ai/user-guide/rendering/).

## Воспроизведение

Из корня репозитория, в отдельном Python 3.13+ окружении:

```powershell
node learning-lab/animations/backprop/export-fixture.ts
python -m venv work/backprop-pilot/venv
work/backprop-pilot/venv/Scripts/python.exe -m pip install -r learning-lab/animations/backprop/requirements.txt
work/backprop-pilot/venv/Scripts/manimgx.exe inspect learning-lab/animations/backprop/backprop.py BackpropSharedNode -t 3.2,6.4,8.4,10,14,19.5,23,26,29,33,35,38,42,end -o work/backprop-pilot/inspect.png
work/backprop-pilot/venv/Scripts/python.exe learning-lab/animations/backprop/render-assets.py
```

Рабочее окружение и storyboard держать вне tracked исходников. Перед повторным
рендером сверить fixture с `sharedGraph`; обновление входов требует повторной
проверки ширины подписей, текста альтернативы и субтитров. `inspect` проверяет
выбранные кадры, а не всю анимацию. Проверки desktop/mobile и доставки `/rust_ml/`
ведутся в общем `PLAN.md`/`PROGRESS.md`. На 2026-10-16 рендер, проверка
14 выбранных кадров и production build прошли. Числа проверяются тестом
`tests/backprop-animation.test.ts`. Подробная браузерная приёмка и её границы —
в [evidence](../../evidence/backprop-pilot-2026-10-16/VALIDATION.md).
Эта запись и связанный pilot evidence относятся к прежнему выпуску без аудио.
Актуальный немой рендер описан в [общем README](../README.md).

Постер: кадр **35.000 s**, когда видна сумма вкладов. `render-assets.py`
сохраняет его из того же `Scene.render(frames=...)`, что создаёт MP4;
FFmpeg не требуется. Pillow используется для записи PNG.

## Таймлайн

| Начало | Конец | Глава и результат |
|---|---|---|
| 00:00 | 00:12 | Прямой расчёт: x и w → q; две ветви → p; затем ошибка L |
| 00:12 | 00:18 | Предсказание: что изменится при малом увеличении q; пауза 3,8 s |
| 00:18 | 00:32 | Обратный расчёт: чувствительность L к p, затем каждый вклад отдельно |
| 00:32 | 00:44 | Два вклада сходятся в сумму; производные по входам; лаборатория |

Внутри четвёртой главы: сумма появляется к 34,2 s, производные по x/w —
к 37,8 s; переход к лаборатории начинается в 40,6 s, текст полностью виден
в 41,2 s. Таймлайн сцены — 44,0 s, файл содержит закрывающий кадр:
браузер сообщает 44,033333 s при 1280×720, 30 fps.
Кнопки частей открывают ключевые кадры 10/14/29/38 s на паузе;
границы самих частей остаются 0/12/18/32 s.

## Плоская текстовая альтернатива

При x=2 и w=3 общий узел q=xw=6. Значение q используется дважды:
в квадрате и напрямую. Получаем p=q²+q=42. Цель равна 2;
ошибка L=(p−2)²/2=800.

Чувствительность ошибки к p равна ∂L/∂p=p−2=40.
Через квадрат вклад в ∂L/∂q равен 40×2q=480.
Через прямое слагаемое вклад равен 40×1=40.
Оба пути начинаются в одном q, поэтому вклады складываются:
∂L/∂q=480+40=520. Оставить только 480 означало бы забыть прямой путь.
Далее ∂L/∂x=520w=1560 и ∂L/∂w=520x=1040.

Самостоятельный следующий шаг: измените x или w в лаборатории,
предскажите оба вклада и объясните, почему в общем узле нужна сумма.
Визуальное движение обозначает зависимость вычислений, а не физический поток.
