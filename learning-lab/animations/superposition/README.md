# Суперпозиция и вмешательство

B12 / R01 R02 R04 R06 / U02 U04 U05 U07 U08.
40 секунд: 0–6 устройство, 6–12 прогноз, 12–26 раскрытие, 26–34 сравнение, 34–40 лаборатория.
Числа из действующей TypeScript-математики. Python только представляет экспорт.

Геометрия: h1, скрытая координата; h2, скрытая координата. Стрелки автоэнкодера и отдельная causal-модель не одна сеть. Таблица содержит вмешательство.

Из каталога learning-lab: `node animations/superposition/export-fixture.ts`; затем native inspect и `python animations/superposition/render-assets.py` в окружении ManimGX. Команды с путями окружения: [общий workflow](../README.md). Ключевые кадры 4/9/22/30/37, постер 30.

Текст, таблица, локальный новый случай и apply/restore доступны без видео. Текущий MP4 выпускается без аудиотрека; SAPI и WAV не нужны. VTT доступны по выбору, приложение не включает их по умолчанию. Исторический narration.ru.json не означает наличие озвучки. Наличие исходников не доказывает браузерную проверку или обучение учеников; GPU и UI проверяет основная задача.

Геометрия автоэнкодера слева и отдельная causal-сеть справа сохраняются одновременно. После паузы прогноза в 12 секунд начинается вмешательство только в правой сети. Видно перемещение чистого h0, неизменные h1/h2 и пересчитанный readout. Обучение автоэнкодера доступно в лаборатории, не выдаётся за причинное вмешательство.
