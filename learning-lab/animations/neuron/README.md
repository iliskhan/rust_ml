# Нейрон: визуальный образец без текстовых слайдов

Класс `NeuronActivation`, 44 секунды. B09/B12; R01/R04/R06; U02/U04/U05/U07/U08.

Новая композиция от 16 октября 2026 сохраняет существующий fixture: x=[1,2], w=[1,−1], вклады [1,−2], b:0→2, z:−1→1, a:0→1. Никакие числа и веса не менялись. Python читает результаты из fixture; только размещение, сложение отрезков и линейная интерполяция задают геометрию.

Два цветных входа связаны с сумматором. Толщина ребра равна 5|w| с минимальной видимой толщиной 1. Импульсы проходят по рёбрам, раскрывая отдельные произведения. Их численные метки переходят на направленные отрезки настоящей числовой оси z. Первый отрезок идёт 0→1, второй 1→−1, начальный bias=0 отмечен точкой. Тот же z передаётся точке ReLU. При изменении b обе точки — на числовой ленте и на ReLU — движутся согласованно через 0.

Нет крупных заголовков и смены экранов. Небольшие подписи Georgia, числовые метки MathTex, одна короткая формула ReLU; фон #090E15. Механизм остаётся в кадре до конца. Нижняя полоса y<−1.8 свободна. Финальный MP4 не содержит аудиодорожки; субтитры доступны по выбору и выключены по умолчанию.

Переход к нулю заканчивается в 30.0 с, движение по положительной ветви начинается в 31.2 с и заканчивается в 33.0 с. Конечные подписи появляются в 33.0–33.5 с, поэтому постер 34 с показывает конечный случай. Во время движения числовые подписи конечных состояний скрыты, геометрические маркеры двигаются по двум отдельным ветвям ReLU.
