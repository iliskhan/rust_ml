# Планирование Беллмана

B12 / R01,R02,R04,R06 / U02,U04,U05,U07,U08.

Фиксированный пример из действующей TS-математики. Числа и ограничения: fixture.json; доступная альтернатива, прогноз и новый случай: fixture.lesson. Общий catalog.ts хранит численный экспорт без второго математического движка.

Причинная геометрия: grid; оси: Сетка известных переходов; Цвет и число: V. V′(s) = maxₐ Σ P(s′|s,a) [r + γ V(s′)].

40 секунд: 0–6 условия, 6–12 прогноз, 12–26 раскрытие, 26–34 сравнение, 34–40 лаборатория. Автопауза на 9; ответ после 12; постер 30. Нижняя зона y<−1.8 оставлена для субтитров и управления.

Экспорт: node animations/rlbellman/export-fixture.ts из learning-lab. Затем render-assets.py с ManimGX 0.1.1: видео без звуковой дорожки. Озвучка отключена по решению пользователя; субтитры необязательны и выключены по умолчанию. Рендер/GPU и реальный браузер проверяются отдельно; наличие исходника не считается такой проверкой.

Геометрическая редакция 2026-10-16: scene_geometry.py показывает формулу, короткие обозначения и движение объектов; текстовые заставки удалены. Проверка без GPU: python animations/vaeposterior/check-scenes.py; --native-objects дополнительно строит реальные MathTex и примитивы без renderer. Это не заменяет осмотр кадров.
