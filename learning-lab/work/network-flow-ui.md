# NetworkFlow3D: состояние реализации

Дата: 2026-10-11, Europe/Moscow. Исходный checkout задания: RustML master `a41e784`.

## Контракт и готовые изменения

- `src/NetworkFlow3D.tsx`: именованный export с props `state`, `kind`, `lr`, `sample`, `onSample`, `onTrainStep`, `onPause`; сам компонент не ведёт параллельное обучение.
- `src/network-flow3d.css`: стили ограничены `.network-flow`, responsive раскладка, reduced-motion.
- Десять ручных стадий: вход, скрытая сумма, tanh, ответ, BCE, δ выхода, δ скрытого слоя, 17 sample-градиентов, среднее четырёх примеров, настоящий шаг родителя.
- SVG показывает 7 нейронов, 12 связей и 5 доступных bias-кнопок. Геометрия условная, через существующие `projectPoint` / `sortByDepth`; новых зависимостей нет. Режим спереди, два ползунка камеры, drag, arrow/Home и mobile pan-y.
- Выбор доступен через SVG, нативный select и таблицу 17 параметров. Карточки явно различают ∂ℓ/∂h и ∂ℓ/∂z, sample ℓ и batch L. Формула текущей стадии скрывается через details; ConceptLink ids проверены в `concepts.ts`.
- Preview использует существующий `optimizerStep` от текущих params/m/v/step. `onTrainStep` вызывается только явной кнопкой, pending-ref защищает от повторного клика. После совпадения полного нового state с ожидаемым появляется подтверждённое before/after; «Следующий цикл» берёт уже обновлённые веса.
- Изменение sample/lr/kind/full state сбрасывает стадию. Новая identity state также распознаётся: reset seed42 на исходном шаге 0 обязан сбросить стадию, хотя числа не изменились. Камера сохраняется.
- `useLearningActive` останавливает визуальные метки при углублении; нет таймера автоплея или автотренера. При взаимодействии вызывается `onPause`. CSS уважает reduced-motion.
