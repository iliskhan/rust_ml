## Исправленные замечания

### R1 · P2 — Escape из числового поля не закрывает разбор

`learning-lab/src/ui.tsx:44`: обработчик любого Escape вызывает
`preventDefault()`, даже когда `draft === null` и ошибки нет. В диалоге
`KnowledgeExplorer` закрытие по Escape выполняется через нативное событие
`cancel`; предотвращённое действие keydown подавляет этот путь. После появления
числовых полей Escape при их фокусе больше не соответствует подсказке «к уроку».

**Исправлено и перепроверено чтением:** в текущей строке 44 Escape
перехватывается только при `draft !== null || invalid`. После отмены следующий
Escape и Escape из нетронутого числового поля не предотвращаются. Координатор
проверяет поведение в настоящем браузере; собственного запуска этого сценария
у ревьюера не было.

### R2 · P2 — переход к ещё загружающейся лаборатории теряется

`learning-lab/src/LessonOutline.tsx:3–6` однократно ищет целевой элемент.
`Experiments.tsx:11` загружает `BoundaryPlayground` через `lazy`, а outline
отрисован до его `Suspense` (`Experiments.tsx:132–135`). При первом открытии урока
на медленном соединении кнопки «Граница и обучение»/«Скрытые представления» уже
доступны, но элементов-целей ещё нет. Клик не меняет фокус/scroll, и после
загрузки не повторяется. Кнопка XOR находится вне lazy-блока и этого ограничения
не имеет.

**Исправлено и перепроверено чтением:** `LessonOutline` перенесён внутрь того
же `Suspense` (`Experiments.tsx:132–135`). До готовности lazy-лаборатории
показывается fallback вместо outline; после mount доступны и кнопки, и цели.
Отложенные события, опрос DOM и новый router не добавлены. Браузерный
регрессионный сценарий: задержать загрузку чанка и убедиться, что outline
появляется вместе с целями, затем проверить все три перехода.

## Браузерные сценарии для окончательной приёмки

1. **Ввод/сброс:** после обучения Boundary открыть подготовку, сфокусировать
   поле и выйти без изменения — шаг/веса/история прежние. Ввести валидную
   новую ширину/η и выйти — один ожидаемый reset; threshold/probe/camera прежние.
2. **Недопустимое число:** пусто, незавершённый минус, за диапазоном, значение
   между разрешёнными шагами; Enter/Tab не передают ошибку в вычисления.
   Исправление валидным значением и Esc снимают ошибку предсказуемо. Проверить
   дробный шаг, целый шаг, ненулевую базу min и большой шаг KV-cache.
3. **Esc/контекст:** открыть понятие, изменить numeric draft, Esc отменяет
   ввод; следующий Esc возвращает в урок. Из нетронутого поля одного Esc
   достаточно. Вложенный переход и breadcrumb возвращают focus/scroll;
   snapshot сохраняет исходные числа, самостоятельный опыт их не меняет.
4. **Навигация:** на холодной загрузке network проверить согласованный mount
   outline/целей; после загрузки все переходы фокусируют видимую цель, hash
   остаётся `#network`, XOR и Boundary сохраняют разные состояния.
5. **3D/числа:** повернуть сцену мышью до дробного угла, затем focus/blur
   нового numeric input без редактирования не меняет угол. Свернуть/вернуться
   к 3D и уйти/вернуться к уроку: камера и hidden-выбор сохранены; обучение
   после ухода остаётся на паузе. Изменение слоёв не создаёт несуществующих осей.
6. **Поверхности:** desktop, 320/390 px, масштаб текста и клавиатура на
   curriculum, neuron, Boundary, одном сложном уроке и dialog; проверить
   фокус, числовые поля, select, длинные labels и отсутствие page overflow.

Build, typecheck, test suite и браузерная приёмка принадлежат координатору.
