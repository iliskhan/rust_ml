## Проверенные границы навыков

Каждая строка соответствует `concept.<id>`; A/B меняют численные случаи или применяемый фрагмент, а не подменяют функцию общим quiz.

| ID | Реализованный фрагмент и перенос |
|---|---|
| function | Квадрат; отрицательный и дробный вход, неоднозначность обратного соответствия |
| slope | Секущая квадрата; отрицательный шаг и отрицательная точка |
| limit | Ошибки секущих; подход с обеих сторон, предел и машинное округление |
| derivative | Производная, линейное и точное изменение; остаток квадратичного члена |
| partial-derivative | Центральная разность по выбранной координате квадратичной функции |
| gradient | Обе компоненты градиента и наклон вдоль единичного направления |
| chain-rule | Аффинная композиция с квадратом и дополнительным линейным путём |
| vector | Покомпонентное сложение, отрицательные элементы, новая длина |
| matrix | Обычное AB, прямоугольные формы, различие AB и BA |
| tensor | Число элементов и построчное смещение, проверка осей и индексов |
| probability | Нормировка неотрицательных масс, масштаб и нулевые компоненты |
| expectation | Среднее с вероятностными весами, сдвиг и одинаковое среднее разных распределений |
| variance | Дисперсия распределения, сдвиг и квадрат масштаба |
| exponential | Сдвинутые экспоненты, большие аргументы, отношения до нормировки |
| logarithm | Сумма отрицательных натуральных логарифмов, независимые события и конечный контракт |
| entropy | Взвешенная неожиданность, нулевые компоненты и перестановка классов |
| softmax | Устойчивая нормировка логитов, общий сдвиг и температура |
| normalization | LayerNorm одного вектора, индивидуальные gamma/beta и нулевая дисперсия |
| loss | MSE без 1/2, несокращающиеся ошибки и усреднение по длине |
| cross-entropy | Прямой log-sum-exp, смена цели и большой ошибочный логит без log(0) |
| learning-rate | Один SGD-шаг на скалярном квадрате, затухающий перескок и чрезмерный шаг |
| backpropagation | q=wx, p=q²+q: сумма двух ветвей, знаки и ненулевая потеря с нулевым градиентом |
| train-validation-test | Train-only fit стандартизатора, применение сохранённых параметров, постоянный признак |
| overfitting | Средние train/heldout потери и разрыв; динамика и выборки разной длины |
| regularization | L2-штраф и градиент выбранных весов, изменение lambda, отключение добавки |
| initialization | Дисперсия и стандартное отклонение He/Xavier, изменение ширины; без генерации RNG |
| batches-epochs | Индексы одной эпохи без отбрасывания хвоста, большой пакет, взвешенное среднее пакетов |
| adamw | Отдельный decay с уже готовым адаптивным направлением, нулевой шаг данных и lambda=0 |
| evaluation | TP/FP/FN/TN, equality порога, дисбаланс и явные флаги неопределённых precision/recall |

Ограничения: secant/limit используют конкретный полином, а не универсальный анализатор пределов;
математические функции не обучают промышленную модель. Overfitting вычисляет наблюдаемый разрыв,
не ставит автоматический причинный диагноз. Initialization выбирает масштаб, не проверяет качество RNG.
AdamW получает уже исправленное адаптивное направление, не повторяет полный расчёт моментов.
Для нулевого знаменателя метрики `Defined=false`, а числовой 0 — явно описанная JSON-заглушка.
Порог и настройки выбираются по validation; test не участвует в fit или подборе.
Индексы примеров, каналов и времени не трактуются как физические координаты.
